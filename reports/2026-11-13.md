# Daily AI Discovery — 2026-11-13

## Category
Coding and developer AI

**Tool:** CodeRabbit — AI Code Review  
**Developer:** CodeRabbit, Inc.  
**Date checked:** 2026-11-13

## Verdict
A PR-focused AI code reviewer, not another code-completion copilot. Its public-repository/open-source plan is free indefinitely and includes AI pull-request reviews. Public repositories with fewer than 10 stars must trigger reviews manually. OSS rate limits apply, but the official pages reviewed do not publish a fixed numeric quota.

## What it does
CodeRabbit reviews proposed code changes in GitHub and GitLab pull requests using codebase context. It can flag possible bugs, edge cases, security and quality issues; explain diffs; and provide PR summaries, AI-slop detection, triage, Change Stack and security reviews on pull requests. It also offers CLI and IDE review workflows.

This is distinct from GitHub Copilot Free, already listed in the history: Copilot's primary use is code completion and in-editor coding assistance, while CodeRabbit is focused on reviewing and validating changes after they are written. CodeRabbit's own FAQ makes this distinction. [Official FAQ](https://www.coderabbit.ai/FAQ)

## Why it is worth trying
It can act as an independent first-pass reviewer before a pull request is merged. That is useful for solo developers, small teams, and projects where code was produced with an AI coding assistant and still needs a separate quality check. The public-repository offer can be tried without a payment card.

## Free tier and exact limits
- **Price:** $0 for public repositories under CodeRabbit's Open Source offer; free indefinitely.
- **Included:** AI pull-request reviews. The OSS offer also includes Team-level features such as slop detection, triage, Change Stack, and security reviews on pull requests.
- **Signup:** Connect a GitHub or GitLab account and install CodeRabbit on a public repository. No application or approval queue is required; no card is required for the OSS offer.
- **Small repositories:** Public repositories with fewer than 10 stars must trigger reviews manually, using the CodeRabbit status comment or `@coderabbitai review` in the pull request.
- **Quota:** CodeRabbit says OSS rate limits apply, but the official pages reviewed do not publish an exact numeric monthly or hourly quota. No fixed quota is inferred here.
- **Private repositories:** The free OSS offer is for public repositories. Private repositories require a paid plan after any trial. The pricing page lists Essentials at $24/user/month billed annually ($30 monthly) and Team at $48/user/month billed annually ($60 monthly).

Sources: [CodeRabbit for Open Source](https://www.coderabbit.ai/oss), [official pricing](https://www.coderabbit.ai/pricing), [official open-source setup guidance updated 2026-11-11](https://kb.coderabbit.ai/articles/8856795235-how-do-i-activate-coderabbit-pro-for-my-open-source-project).

## Main limits and cautions
- A public repository is required for the permanent free OSS offer.
- OSS-specific rate limits apply; their exact numeric threshold was not published in the official sources checked.
- Repositories with fewer than 10 stars need manual review triggering.
- AI findings can be false positives or miss issues. Treat suggestions as review input, not proof of correctness; keep human review, tests and security checks.
- Full-codebase Deep Scans and some on-demand products may have separate usage pricing.
- **Privacy:** CodeRabbit's Privacy Notice says OSS review data is excluded from its no-training representation and may be used to train its systems. It also says certain review-improvement data, primarily vector embeddings, may be stored, with an opt-out. Read this before connecting a public repository, especially if it contains information that should not be shared. [Privacy Notice](https://www.coderabbit.ai/privacy-policy)

## Quality and adoption evidence

### Independent benchmark
The live [Martian Code Review Bench](https://www.codereviewbenchmark.com/) was checked on 2026-11-13. Its online leaderboard showed CodeRabbit at **#5**, with **61.3% F1**, **69.8% precision**, and **54.6% recall** in the current view. This is a continuously updated benchmark; rankings can move as the sample changes and should not be treated as a guarantee for an individual repository.

### Vendor-reported adoption
In an article dated 2026-10-08, CodeRabbit reported **1,049,817 open-source reviews in September 2026** and installations on **300,000+ public repositories**. The company notes that completed reviews include repeat reviews of the same pull request. These are vendor-reported figures, not an independent audit. [Vendor report](https://www.coderabbit.ai/blog/one-million-open-source-reviews-september-2026)

GitHub Marketplace showed a verified publisher and **369,621 installs** when checked. Marketplace installs indicate adoption, not review accuracy. [GitHub Marketplace listing](https://github.com/marketplace/coderabbitai)

### Anecdotal community feedback
A Reddit developer described CodeRabbit catching a privacy/logic flaw involving anonymous commenters. This is one user's experience, not a controlled test. [Reddit discussion](https://www.reddit.com/r/coderabbit/comments/1qgzcc9/coderabbit_review_caught_logic_leak/)

Trustpilot showed **10 reviews and a 2.1/5 TrustScore** when checked, including recent complaints about paid-plan billing and rate limits. The sample is very small and self-selected, and those complaints are not a representative assessment of the free public-repository offer. [Trustpilot reviews](https://www.trustpilot.com/review/coderabbit.ai)
